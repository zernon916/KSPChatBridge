# Next release - notes draft (used when the release is cut)

- AICS MFD: one resizable cockpit-style panel (engraved title plate, MASTER ALARM annunciator, 8 soft keys per side + 8 bottom + spare top row); everything scales with the window.
- Native IVA AICS MFD in the Mk1 / Mk2 inline / Mk1-3 / Mk2 / Mk1 inline cockpits, clickable keys and keyboard typing.
- COMMS group (INTERCOM / SYSTEM / PILOT / ALL) replaces the chat window (still optional); MASTER ALARM, SYSTEMS and STATUS are MFD pages.
- MAP / CHART / ILS are display-only screens; all actions on bezel soft keys.
- Taxi ground charts (taxi to hangar / runway 09 / 27), derotation after touchdown, MechJeb page.
- Setting "RPM AICS pages: auto/on/off".
- AICS is single-player only; multiplayer is not supported or tested.

## Docs
- `AUTOPILOT_OVERHAUL.md` - the in-mod autopilot overhaul: design, learned per-craft profiles and the 5 plane test-flight plan.
- `GLOSSARY.md` - plain-language definitions (LEARN, profile, Vs, TWR, lead-turn, flare, entry chart, ThrottleGate, suicide burn).
- `TEST_FLIGHT_CHECKLIST.md` - printable pass/fail checklist for the 5 plane test flights.
- KWT - optional external reference for envelope plots (stall / max level speed / climb rate); AICS never reads it and there is no dependency.
